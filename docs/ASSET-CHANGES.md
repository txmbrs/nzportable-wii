# Asset provenance and Wii changes

Original game assets: NZP Team and contributors, https://github.com/nzp-team/assets.
Upstream asset terms: CC BY-SA 4.0, with component attributions preserved in
`nzp/licenses/attributions.txt`. See LICENSE-NZP-ASSETS.md and the full CC text.

The full Wii app uses the local port's assembled NZPortable data. Wii-specific
additions include the smooth font/kerning and hit-marker/HUD image changes.
Modified asset contributions are distributed under CC BY-SA 4.0 as applicable;
the font software retains its SIL Open Font License notice.

The online compatibility overlay is assembled from NZPortable assets so the
experimental client can use the shared game data. Cached game/progs packages are
included to avoid requiring them at first connection. This is an unofficial
port; the original authors do not endorse this release.
